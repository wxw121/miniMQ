## 8. Important Design Constraints / 重要设计约束

- `mq-storage` must remain independent of Netty.
- Each selected segment contributes at most one contiguous file slice.
- Sparse index supplies the floor position; metadata scanning finds the exact
  first record and byte boundary.
- The first eligible record may exceed `maxBytes`, but later records may not.
- A `FetchPlan` owns the reader lease until network completion, failure,
  timeout, or channel close.
- Retention/compaction returns `SKIPPED_READERS` while a plan is active.
- Heap fallback is selected only before any response byte is queued.
- A failure after queueing the prefix closes the channel instead of appending a
  second response.
- TLS uses heap fallback in V2.2.
- The wire protocol stays at version 1 and the 16 MiB frame limit remains.
