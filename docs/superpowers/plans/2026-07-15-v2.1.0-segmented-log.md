# V2.1.0 Segmented Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace MiniMQ's single partition file with size-rolled segmented
logs and sparse indexes while retaining V2.0 WAL/checkpoint recovery and
migrating legacy files safely.

**Closeout status:** Implemented on branch `dev/v2.1.0-segmented-log`.
Tasks 1-6 are covered by the V2.1.0 closeout report at
`docs/test-report-2026-07-15-v2.1.0-segmented-log.md`. The checkboxes below are
kept as the original execution plan structure.

**Architecture:** `LogManager` retains ownership of the V2.0 WAL, checkpoint,
and flush policy, while opening `SegmentedPartitionLog` instances below
`dataDir/segments`. Each partition log owns an ordered catalog, one active
appendable segment, sealed read-only segments, and a sparse index per segment.
Broker, protocol, producer, and consumer APIs do not change.

**Tech Stack:** Java 17, Maven, JUnit 5, Jackson, `FileChannel`, JaCoCo.

## Global Constraints

- Preserve append ordering: allocate offset, append WAL intent, append record,
  then apply V2.0 flush and checkpoint policy.
- Keep `PartitionLog` as the broker-facing API and retain
  `LogManagerConfig(FlushPolicy, int)` source compatibility.
- Keep the binary record format:
  `[long offset][int key length][key][int value length][value]`.
- Require strictly increasing offsets, but allow reads to traverse offset holes.
- Truncate only incomplete tails in the active highest-base segment. A malformed
  or incomplete sealed segment fails startup.
- Exclude retention, compaction, replicas, service discovery, Epoll, mmap, and
  sendfile from V2.1.0.
- Every behavior is test-first. The full `mvn verify` command must retain the
  existing 90% JaCoCo line threshold.

```java
final class SparseOffsetIndex implements AutoCloseable {
    static final int ENTRY_BYTES = Long.BYTES * 2;
    private final FileChannel channel;
    private final List<IndexEntry> entries;

    static SparseOffsetIndex open(Path path) throws IOException;
    void append(long offset, long filePosition);
    long floorPosition(long targetOffset);
    void replace(List<IndexEntry> entries);
    record IndexEntry(long offset, long filePosition) { }
}
```

`open` must create the parent directory, open the channel with `CREATE`,
`READ`, and `WRITE`, reject a size not divisible by `ENTRY_BYTES`, then read
each pair in order into `entries`. It rejects negative positions and entries
whose offset or position is not greater than the preceding one. `append`
performs the same monotonic validation against the last entry, writes both
longs fully, and appends the immutable entry to the list. `floorPosition`
binary-searches the list and returns the matched entry position or zero.
`replace` validates a defensive copy with the same rules, truncates the channel,
writes every pair fully, and replaces `entries` only after the writes succeed.

- [ ] **Step 3: Implement segment lifecycle**

```java
public final class SegmentedPartitionLog implements PartitionLog {
    public SegmentedPartitionLog(Path partitionDir, SegmentedLogConfig config) throws IOException;
    @Override public synchronized long append(byte[] key, byte[] value);
    @Override public synchronized void appendAt(long offset, byte[] key, byte[] value);
    @Override public synchronized List<Record> read(long fromOffset, int maxBytes);
    @Override public synchronized long highWatermark();
    @Override public synchronized void flush();
    @Override public synchronized void close();
}
```

Constructor sequence: create `partitionDir`; load `catalog.json`; when absent,
discover paired twenty-digit filenames in ascending order and publish a rebuilt
catalog, or create and publish base segment zero when none exist. Open every
catalog descriptor through `SegmentFile.open`; mark only the final descriptor
active. `SegmentFile.open` scans its log with the Task 1 codec and either
validates its index or rebuilds it. Only the highest-base segment may truncate
from an `IncompleteRecordException`; all others turn it into a storage failure.

`append` delegates to `appendAt(nextOffset, key, value)`. `appendAt` reads and
compares an existing offset when it is below `nextOffset`, throws on a payload
mismatch, and rejects an offset above `nextOffset`. For an equal offset, it
calculates codec size; if the active segment is non-empty and the new bytes
would exceed the maximum, it creates a segment at that offset, adds its
descriptor to a generation-incremented catalog, forces and publishes the
catalog, then switches the active segment. It writes the record, adds the first
and every configured stride record to the sparse index, and advances
`nextOffset`.

`read` chooses the greatest base no greater than `fromOffset`, asks that
segment index for its floor position, and scans records from that byte through
all later segments until the next encoded record would exceed `maxBytes`.
`flush` forces every open log and index channel. `close` calls `flush`, closes
all channels, and rejects future calls.

```java
public PartitionLog getOrCreate(String topic, int partitionId) {
    ensureOpen();
    String key = topic + "-" + partitionId;
    return logs.computeIfAbsent(key, this::openPartitionLog);
}

private PartitionLog openPartitionLog(String key) {
    Path segmentedDir = dataDir.resolve("segments").resolve(key);
    Path legacyFile = dataDir.resolve(key + ".log");
    try {
        if (!Files.exists(segmentedDir) && Files.exists(legacyFile)) migrateLegacyLog(legacyFile, segmentedDir);
        return new SegmentedPartitionLog(segmentedDir, config.segmentedLogConfig());
    } catch (IOException e) {
        throw new IllegalStateException("Failed to open segmented log " + key, e);
    }
}
```
