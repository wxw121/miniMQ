# MiniMQ Implementation Plan / MiniMQ 实施计划

> **For agentic workers / 给 agent 工作者：** REQUIRED SUB-SKILL / 必需子技能：Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. / 使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 按任务实现本计划。Steps use checkbox (`- [ ]`) syntax for tracking. / 步骤使用 checkbox（`- [ ]`）语法追踪。

**Goal / 目标：** 实现 Kafka 风格的 Java 分布式消息队列 MiniMQ V1（Producer + Consumer Group + 3 Broker 集群）

**Architecture / 架构：** Netty 二进制协议 + Append-Only Log 存储 + Broker-0 Controller；分区 round-robin 分布到 3 Broker，Consumer Group 由 Controller 协调。

**Tech Stack / 技术栈：** Java 17, Maven, Netty 4.1, JUnit 5, Jackson, SLF4J/Logback

**Spec / 规格文档：** `docs/superpowers/specs/2026-06-30-java-mq-design.md`

## Implementation Notes / 实施备注

- **REGISTER_BROKER (ApiKey=9):** spec 未列出，V1 实现 Broker 启动自注册，Request: `BrokerId(4)+Host+Port`
- **Controller 地址:** 非 Controller Broker 通过 `--controller-addr localhost:9092` 连接
- **测试优先:** 每个模块先写单元测试再实现
- **NOT_LEADER:** 非 Leader Broker 收到 PRODUCE/FETCH 返回 error code 3
