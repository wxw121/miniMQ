# MiniMQ V2.2 Read Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move MiniMQ to `2.2.0-SNAPSHOT` and implement an end-to-end Broker FETCH sendfile path over segmented logs and sparse indexes without weakening retention or compaction safety.

**Architecture:** `mq-storage` produces immutable `FetchPlan` objects containing stable file slices and a reader lease; `mq-protocol` encodes a FETCH frame prefix whose declared length includes those slices; `mq-broker` writes the prefix followed by Netty `DefaultFileRegion` objects and releases the lease from one idempotent completion path. The current heap response remains the fallback selected before any response bytes are emitted.

**Tech Stack:** Java 17, Maven reactor, JUnit 5, Netty 4.1, append-only segmented logs, sparse offset indexes, JaCoCo.

## Global Constraints

- Every reactor POM and versioned command example must use exactly `2.2.0-SNAPSHOT`.
- `mq-storage` must not depend on Netty; storage exposes only `Path`, positions, lengths, counts, and lifecycle objects.
- The MiniMQ wire protocol stays at `MqFrame.VERSION == 1`; record encoding remains `offset + keyLength + key + valueLength + value`.
- The complete frame remains bounded by `MqFrame.MAX_FRAME_BYTES == 16 * 1024 * 1024`.
- Transfer modes are exactly `AUTO` and `HEAP`; `AUTO` is the default.
- Fetch transfer timeout defaults to exactly `30_000` milliseconds and must be positive.
- Heap fallback is allowed only before any response byte is queued and only for explicit HEAP mode or unsupported capability.
- Segment/index corruption, file-open failure, frame overflow, and failures after queueing the prefix must never silently fall back.
- An open `FetchPlan` counts as an active reader; retention and compaction return `SKIPPED_READERS` without mutation.
- A timed-out or failed in-flight transfer closes the channel and idempotently releases file resources and the reader lease.
- Do not add mmap, TLS zero-copy, replication, service discovery, circuit breakers, Epoll, persistent metrics, a new admin protocol, or a new benchmark dependency.
- Normal CI must not assert a timing percentage; benchmark output must prove the exercised path through transfer metrics.
- The full reactor must continue to pass the existing 90 percent JaCoCo line-coverage gate.

## File Structure

- `mq-storage/.../FileRegionSlice.java`: public immutable description of one transferable file range.
- `mq-storage/.../FetchPlan.java`: public immutable fetch metadata plus idempotent reader-lease cleanup.
- `mq-storage/.../TransferablePartitionLog.java`: optional storage capability consumed by the Broker.
- `mq-storage/.../PartitionLogRecordCodec.java`: shared full decoder and metadata-only scanner.
- `mq-storage/.../SegmentFile.java`: sparse-index-based planning for one physical segment.
- `mq-storage/.../SegmentedPartitionLog.java`: cross-segment planning and reader snapshot ownership.
- `mq-protocol/.../ProtocolSerdes.java`: FETCH prefix encoding with trailing file bytes included in frame length.
- `mq-broker/.../FetchTransferMode.java`: AUTO/HEAP configuration enum.
- `mq-broker/.../FetchTransferMetrics.java`: mutable process counters with immutable snapshots.
- `mq-broker/.../FetchTransferMetricsSnapshot.java`: public metric snapshot.
- `mq-broker/.../handler/FetchResponseWriter.java`: heap/sendfile selection, Netty writes, timeout, and cleanup.
- `mq-broker/.../handler/MqRequestHandler.java`: delegates successful FETCH responses to the writer.
- `mq-broker/.../BrokerConfig.java`: transfer mode and timeout parsing.
- `mq-broker/.../BrokerServer.java`: owns shared metrics and wires the writer.
- `mq-demo/.../FetchBenchmark.java`: deterministic heap versus sendfile benchmark runner.
- `mq-demo/.../DemoCli.java`: exposes the `benchmark-fetch` command.

```java
static ScannedRecord scan(FileChannel channel, long startPosition, long fileSize) throws IOException {
    if (startPosition < 0 || startPosition > fileSize) {
        throw new IOException("Invalid partition log position " + startPosition);
    }
    channel.position(startPosition);
    long offset = readLong(channel, fileSize);
    if (offset < 0) {
        throw new IOException("Corrupt partition log at byte " + startPosition
                + ": negative offset " + offset);
    }
    skipField(channel, fileSize, "key", startPosition);
    skipField(channel, fileSize, "value", startPosition);
    long nextPosition = channel.position();
    return new ScannedRecord(offset, startPosition, nextPosition,
            Math.toIntExact(nextPosition - startPosition));
}

private static void skipField(
        FileChannel channel, long fileSize, String fieldName, long recordStart) throws IOException {
    ByteBuffer lengthBuffer = ByteBuffer.allocate(Integer.BYTES);
    readFully(channel, lengthBuffer, fileSize);
    int length = lengthBuffer.getInt(0);
    validateFieldLength(length, fieldName, recordStart);
    if (length > 0) {
        if (fileSize - channel.position() < length) {
            throw new IncompleteRecordException();
        }
        channel.position(channel.position() + length);
    }
}

private static void validateFieldLength(int length, String fieldName, long recordStart) throws IOException {
    if (length < NULL_LENGTH || length > MAX_FIELD_LENGTH) {
        throw new IOException("Corrupt partition log at byte " + recordStart
                + ": invalid " + fieldName + " length " + length);
    }
}

}
```

```java
package com.minimq.storage;

import java.util.List;
import java.util.concurrent.atomic.AtomicBoolean;

public final class FetchPlan implements AutoCloseable {
    private final long highWatermark;
    private final int recordCount;
    private final int recordBytes;
    private final List<FileRegionSlice> slices;
    private final Runnable closeAction;
    private final AtomicBoolean closed = new AtomicBoolean();

    FetchPlan(long highWatermark, int recordCount, int recordBytes,
              List<FileRegionSlice> slices, Runnable closeAction) {
        if (highWatermark < 0 || recordCount < 0 || recordBytes < 0) {
            throw new IllegalArgumentException("fetch plan values must be non-negative");
        }
        this.highWatermark = highWatermark;
        this.recordCount = recordCount;
        this.recordBytes = recordBytes;
        this.slices = List.copyOf(slices);
        this.closeAction = closeAction;
    }

    public long highWatermark() { return highWatermark; }
    public int recordCount() { return recordCount; }
    public int recordBytes() { return recordBytes; }
    public List<FileRegionSlice> slices() { return slices; }

    @Override
    public void close() {
        if (closed.compareAndSet(false, true)) {
            closeAction.run();
        }
    }
}
```

```java
record PlannedRead(int recordCount, int recordBytes, FileRegionSlice slice) {

synchronized PlannedRead planRead(
        long fromOffset, int maxBytes, long highWatermark, boolean allowOversizedFirst) throws IOException {
    ensureOpen();
    if (maxBytes <= 0 || !hasRecords() || firstOffset >= highWatermark || lastOffset < fromOffset) {
        return new PlannedRead(0, 0, null);
    }
    long fileSize = logChannel.size();
    long position = index.floorPosition(fromOffset);
    long sliceStart = -1;
    long sliceEnd = -1;
    int recordCount = 0;
    int recordBytes = 0;
    while (position < fileSize) {
        PartitionLogRecordCodec.ScannedRecord scanned =
                PartitionLogRecordCodec.scan(logChannel, position, fileSize);
        position = scanned.nextPosition();
        if (scanned.offset() >= highWatermark) {
            break;
        }
        if (scanned.offset() < fromOffset) {
            continue;
        }
        if (recordBytes + scanned.encodedBytes() > maxBytes
                && (recordCount > 0 || !allowOversizedFirst)) {
            break;
        }
        if (sliceStart < 0) {
            sliceStart = scanned.startPosition();
        }
        sliceEnd = scanned.nextPosition();
        recordCount++;
        recordBytes += scanned.encodedBytes();
    }
    FileRegionSlice slice = recordCount == 0
            ? null
            : new FileRegionSlice(logPath, sliceStart, sliceEnd - sliceStart);
    return new PlannedRead(recordCount, recordBytes, slice);
}
```

```java
@Override
public FetchPlan planFetch(long fromOffset, int maxBytes) {
    ReadSnapshot snapshot = acquireReadSnapshot();
    try {
        ensureOpen();
        final long fetchHighWatermark;
        final List<SegmentFile> segmentSnapshot;
        synchronized (this) {
            fetchHighWatermark = nextOffset;
            segmentSnapshot = List.copyOf(segments);
        }
        if (maxBytes <= 0) {
            return new FetchPlan(fetchHighWatermark, 0, 0, List.of(), snapshot::close);
        }
        int recordCount = 0;
        int recordBytes = 0;
        List<FileRegionSlice> slices = new ArrayList<>();
        int startIndex = segmentIndexFor(segmentSnapshot, fromOffset);
        for (int i = startIndex; i < segmentSnapshot.size(); i++) {
            if (recordCount > 0 && recordBytes >= maxBytes) {
                break;
            }
            int remaining = Math.max(1, maxBytes - recordBytes);
            SegmentFile.PlannedRead planned =
                    segmentSnapshot.get(i).planRead(
                            fromOffset, remaining, fetchHighWatermark, recordCount == 0);
            if (planned.recordCount() == 0) {
                continue;
            }
            recordCount += planned.recordCount();
            recordBytes += planned.recordBytes();
            slices.add(planned.slice());
        }
        return new FetchPlan(fetchHighWatermark, recordCount, recordBytes, slices, snapshot::close);
    } catch (IOException | RuntimeException failure) {
        snapshot.close();
        throw new IllegalStateException("Failed to plan segmented fetch", failure);
    }
}
```

```java
private static ByteBuf wrapFrame(ByteBuf payload, int trailingBytes) {
    final int length;
    try {
        length = Math.addExact(payload.readableBytes(), trailingBytes);
    } catch (ArithmeticException overflow) {
        payload.release();
        throw new IllegalArgumentException("Frame length overflow", overflow);
    }
    if (trailingBytes < 0 || length > MqFrame.MAX_FRAME_BYTES) {
        payload.release();
        throw new IllegalArgumentException("Frame is too large: " + length);
    }
    ByteBuf frame = Unpooled.buffer(2 + 1 + 4 + payload.readableBytes());
    frame.writeShort(MqFrame.MAGIC);
    frame.writeByte(MqFrame.VERSION);
    frame.writeInt(length);
    frame.writeBytes(payload);
    payload.release();
    return frame;
}
```

```java
    }

    FetchResponseWriter(FetchTransferMode mode, long timeoutMs,
                        FetchTransferMetrics metrics,
                        Predicate<Channel> fileRegionSupported) {
        this.mode = mode;
        this.timeoutMs = timeoutMs;
        this.metrics = metrics;
        this.fileRegionSupported = fileRegionSupported;
    }

    boolean write(ChannelHandlerContext ctx, MqResponseHeader header,
                  FetchRequest request, PartitionLog log) {
        if (mode == FetchTransferMode.HEAP) {
            metrics.recordHeapMode();
            writeHeap(ctx, header, request, log);
            return true;
        }
        if (!(log instanceof TransferablePartitionLog transferable)) {

            writeHeap(ctx, header, request, log);
            return true;

            writeHeap(ctx, header, request, log);
            return true;

            metrics.recordUnsupportedPipeline();
            writeHeap(ctx, header, request, log);
            return true;

        writeSendfile(ctx, header, request, transferable);
```

```java
private static final class TransferCleanup implements Runnable {

    @Override
```
