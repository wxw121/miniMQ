# MiniMQ V2.5.0 Broker Leases And Automatic Failover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use $superpower-subagents (recommended) or $superpower-executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking via update_plan.

**Goal:** Add Broker heartbeat leases, self-fencing, automatic LEO-aware failover, safe frozen partitions, and bounded client recovery while keeping the static Controller architecture.

**Architecture:** `ClusterController` owns persisted broker epochs and in-memory lease deadlines; `BrokerLeaseMonitor` expires leases on a dedicated scheduler. Each Broker has one `BrokerLeaseService` and one `BrokerAvailabilityGuard`; the Broker fences data-plane work before the Controller lease can expire, then performs full registration and metadata sync before recovery.

**Tech Stack:** Java 17, Maven multi-module build, Netty 4.1, Jackson metadata persistence, JUnit 5, JaCoCo.

Implement registration with copy-before-save semantics:

```java
public synchronized BrokerRegistration registerBroker(RegisterBrokerRequest request) {
    long now = nanoTime.getAsLong();
    BrokerEntry current = metadata.brokers.get(request.brokerId());
    BrokerLease lease = brokerLeases.get(request.brokerId());
    if (current != null && current.online && lease != null && now < lease.deadlineNanos()) {
        return BrokerRegistration.failed(ErrorCode.BROKER_ID_IN_USE);
    }

    ClusterMetadata next = copyMetadata(metadata);
    BrokerEntry entry = next.brokers.computeIfAbsent(request.brokerId(), ignored -> new BrokerEntry());
    entry.brokerId = request.brokerId();
    entry.host = request.host();
    entry.port = request.port();
    entry.online = true;
    entry.brokerEpoch = current == null ? 1L : Math.addExact(current.brokerEpoch, 1L);
    restoreFrozenPartitions(next, request.brokerId());
    metadataStore.save(next);
    metadata = next;
    brokerLeases.put(request.brokerId(), new BrokerLease(
            entry.brokerEpoch, now + TimeUnit.MILLISECONDS.toNanos(leaseTimeoutMs)));
    return new BrokerRegistration(
            ErrorCode.NONE, new RegisterBrokerResponse(entry.brokerEpoch, leaseTimeoutMs));
}
```

`restoreFrozenPartitions` must only unfreeze partitions whose retained `leaderBrokerId` equals the registering Broker; it sets `frozen = false` and `isrBrokerIds = new ArrayList<>(List.of(brokerId))`.

- [ ] **Step 6: Implement heartbeat and atomic expiry**

```java
public synchronized ErrorCode heartbeatBroker(BrokerHeartbeatRequest request) {
    BrokerEntry broker = metadata.brokers.get(request.brokerId());
    BrokerLease lease = brokerLeases.get(request.brokerId());
    long now = nanoTime.getAsLong();
    if (broker == null || !broker.online || broker.brokerEpoch != request.brokerEpoch()
            || lease == null || lease.brokerEpoch() != request.brokerEpoch()
            || now >= lease.deadlineNanos()) {
        return ErrorCode.BROKER_FENCED;
    }
    brokerLeases.put(request.brokerId(), new BrokerLease(
            request.brokerEpoch(), now + TimeUnit.MILLISECONDS.toNanos(leaseTimeoutMs)));
    return ErrorCode.NONE;
}

public synchronized int expireOverdueBrokerLeases() {
    long now = nanoTime.getAsLong();
    List<BrokerLeaseKey> expired = brokerLeases.entrySet().stream()
            .filter(entry -> now >= entry.getValue().deadlineNanos())
            .map(entry -> new BrokerLeaseKey(entry.getKey(), entry.getValue().brokerEpoch()))
            .toList();
    int applied = 0;
    for (BrokerLeaseKey key : expired) {
        if (expireBrokerLease(key.brokerId(), key.brokerEpoch())) {
            applied++;
        }
    }
    return applied;
}
```

`expireBrokerLease` must modify a copied `ClusterMetadata`, select replacements against that copy, freeze only partitions with no online ISR replacement, call `metadataStore.save(next)`, then assign `metadata = next` and remove only the matching epoch lease. If the Broker is already offline, remove the matching stale lease and return `false` without saving. Manual `markBrokerOffline` keeps its current “reject last ISR Leader” behavior but removes its current lease only after metadata persistence succeeds.

Change `normalizePartition` so `frozen` partitions retain an empty ISR and are not passed to `reconcileIsrByLeo`. Update all copy methods and `toPartitionMetadata` for `brokerEpoch` and `frozen`.

```java
public final class BrokerAvailabilityGuard {
    public enum State { STARTING, ACTIVE, FENCED, RECOVERING }

    private final AtomicReference<State> state = new AtomicReference<>(State.STARTING);

    public State state() { return state.get(); }
    public boolean allowsDataPlane() { return state() == State.ACTIVE; }
    public boolean allowsMaintenanceRun() { return state() == State.ACTIVE; }
    public boolean allowsMaintenanceRead() { return true; }
    public ErrorCode rejectionError() { return ErrorCode.BROKER_FENCED; }
    public void activate() { state.set(State.ACTIVE); }
    public void fence() { state.set(State.FENCED); }
    public void startRecovering() { state.set(State.RECOVERING); }
}
```

```java
void runOnce() {
    if (guard.state() != BrokerAvailabilityGuard.State.ACTIVE) {
        recover();
        return;

    try {
        heartbeat(new BrokerHeartbeatRequest(config.brokerId(), brokerEpoch));

}
```
