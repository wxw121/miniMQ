# V2.3.1 LEO-Aware Promotion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use $superpower-subagents (recommended) or $superpower-executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking via update_plan.

**Goal:** Persist Controller-visible replica LEO values and elect the online ISR replica with the highest known LEO when a leader goes offline.

**Architecture:** Extend partition metadata with a broker-to-LEO map and carry it through persistence, snapshots, and the metadata protocol. Broker request handling reports leader and follower progress to ClusterController, while leader failover ranks eligible ISR replicas by LEO and uses configured replica order as the deterministic tie-breaker.

**Tech Stack:** Java 17, Maven, JUnit 5, Netty ByteBuf, Jackson metadata persistence, JaCoCo.

    public synchronized ErrorCode updateReplicaLogEndOffset(
            String topicName, int partitionId, int brokerId, long logEndOffset) {
        PartitionEntry partition = getPartitionEntry(topicName, partitionId);
        if (partition == null || logEndOffset < 0
                || !partition.replicaBrokerIds.contains(brokerId)) {
            return ErrorCode.INVALID_REQUEST;
        }
        normalizePartition(partition);
        long current = partition.replicaLogEndOffsets.getOrDefault(brokerId, 0L);
        if (logEndOffset >= current) {
            partition.replicaLogEndOffsets.put(brokerId, logEndOffset);
            metadataStore.save(metadata);
        }
        return ErrorCode.NONE;
    }

    public synchronized long replicaLogEndOffset(
            String topicName, int partitionId, int brokerId) {
        PartitionEntry partition = getPartitionEntry(topicName, partitionId);
        return partition == null ? 0L
                : partition.replicaLogEndOffsets.getOrDefault(brokerId, 0L);
    }

During topic creation, initialize each replica to 0L. During normalization, create a missing map and add missing replica entries with 0L. Copy the map in copyTopic so snapshots cannot mutate Controller state.

- [ ] **Step 3: Rank eligible candidates by LEO**

Replace the early return loop with a single pass that only replaces the selected broker for a strictly larger LEO. This preserves replica order on equal values.

    Integer selectedBrokerId = null;
    long selectedLeo = Long.MIN_VALUE;
    for (int replicaId : partition.replicaBrokerIds) {
        BrokerEntry replica = metadata.brokers.get(replicaId);
        if (replicaId == offlineBrokerId
                || !partition.isrBrokerIds.contains(replicaId)
                || replica == null
                || !replica.online) {
            continue;
        }
        long replicaLeo = partition.replicaLogEndOffsets.getOrDefault(replicaId, 0L);
        if (selectedBrokerId == null || replicaLeo > selectedLeo) {
            selectedBrokerId = replicaId;
            selectedLeo = replicaLeo;
        }
    }
    return selectedBrokerId;
