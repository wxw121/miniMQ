# V2.1.1 Retention And Compaction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add time/size retention, sealed-segment-only compaction, atomic catalog publication, and read snapshot protection on top of the V2.1.0 segmented log layout.

**Architecture:** Keep the broker data path on `LogManager` and `PartitionLog`, and add storage maintenance as an opt-in `LogMaintenanceConfig`. Retention removes whole sealed segments by publishing a new catalog before deleting obsolete files. Compaction rewrites only sealed segment files through `.cleaned` staging files, keeps original offsets, and blocks physical replacement until in-flight readers have left their catalog snapshot.

**Tech Stack:** Java 17, Maven reactor, JUnit 5, Jackson catalog JSON, existing `WriteAheadLog`, `CheckpointStore`, `SegmentedPartitionLog`, and `SparseOffsetIndex`.

## Global Constraints

- Keep the project on Java 17.
- Move the active development version from `2.1.0-SNAPSHOT` to `2.1.1-SNAPSHOT`.
- Preserve the existing `PartitionLog` broker-facing API.
- Preserve existing `LogManagerConfig(FlushPolicy, int)` source compatibility.
- Retention and compaction must never operate on the active segment.
- Compacted records must keep their original absolute offsets; holes are expected.
- Null keys are retained during compaction.
- Catalog replacement must be published before obsolete retention files are deleted.
- Temporary `.cleaned` and `.obsolete` files must be ignored or cleaned during startup recovery.
- Full Maven verification must keep the 90 percent JaCoCo line-coverage gate passing.

```java
public record RetentionPolicy(long retentionMs, long retentionBytes) {
    public RetentionPolicy {
        if (retentionMs < 0) {
            throw new IllegalArgumentException("retentionMs must be non-negative");
        }
        if (retentionBytes < 0) {
            throw new IllegalArgumentException("retentionBytes must be non-negative");
        }
    }

    public static RetentionPolicy disabled() {
        return new RetentionPolicy(0, 0);
    }

    public static RetentionPolicy of(long retentionMs, long retentionBytes) {
        return new RetentionPolicy(retentionMs, retentionBytes);
    }

    public boolean enabled() {
        return retentionMs > 0 || retentionBytes > 0;
    }
}
```

```java
public record CompactionPolicy(boolean enabled, int maxSegmentsPerRun) {
    public CompactionPolicy {
        if (enabled && maxSegmentsPerRun <= 0) {
            throw new IllegalArgumentException("maxSegmentsPerRun must be positive when compaction is enabled");
        }
        if (!enabled && maxSegmentsPerRun < 0) {
            throw new IllegalArgumentException("maxSegmentsPerRun must be non-negative");
        }
    }

    public static CompactionPolicy disabled() {
        return new CompactionPolicy(false, 0);
    }

    public static CompactionPolicy enabled(int maxSegmentsPerRun) {
        return new CompactionPolicy(true, maxSegmentsPerRun);
    }
}
```

```java
public record LogMaintenanceConfig(
        RetentionPolicy retentionPolicy,
        CompactionPolicy compactionPolicy,
        int maintenanceEveryNAppends) {
    public LogMaintenanceConfig {
        if (retentionPolicy == null) {
            throw new IllegalArgumentException("retentionPolicy is required");
        }
        if (compactionPolicy == null) {
            throw new IllegalArgumentException("compactionPolicy is required");
        }
        if (maintenanceEveryNAppends < 0) {
            throw new IllegalArgumentException("maintenanceEveryNAppends must be non-negative");
        }
    }

    public static LogMaintenanceConfig disabled() {
        return new LogMaintenanceConfig(RetentionPolicy.disabled(), CompactionPolicy.disabled(), 0);
    }

    public static LogMaintenanceConfig of(
            RetentionPolicy retentionPolicy,
            CompactionPolicy compactionPolicy,
            int maintenanceEveryNAppends) {
        return new LogMaintenanceConfig(retentionPolicy, compactionPolicy, maintenanceEveryNAppends);
    }

    public boolean enabled() {
        return retentionPolicy.enabled() || compactionPolicy.enabled();
    }

    public boolean shouldRunAfterAppend(long successfulAppends) {
        return enabled() && maintenanceEveryNAppends > 0
                && successfulAppends % maintenanceEveryNAppends == 0;
    }
}
```

- [ ] **Step 3: Implement `SegmentCompactor` key selection**

Use a private immutable byte-array key wrapper:

```java
final class ByteArrayKey {
    private final byte[] bytes;
    ByteArrayKey(byte[] bytes) {
        this.bytes = java.util.Arrays.copyOf(bytes, bytes.length);
    }
    @Override public boolean equals(Object other) {
        return other instanceof ByteArrayKey key && java.util.Arrays.equals(bytes, key.bytes);
    }
    @Override public int hashCode() {
        return java.util.Arrays.hashCode(bytes);
    }
}
```

Algorithm:
- Pick at most `maxSegmentsPerRun` sealed segments from oldest to newest.
- Read all later segments, including active, to seed `newerKeys`.
- Walk selected sealed segments newest-to-oldest and record-newest-to-oldest.
- Keep null-key records unconditionally.
- Keep a keyed record only when its key is not already in `newerKeys`, then add the key.
- Write kept records back to each original segment base in original offset order.
