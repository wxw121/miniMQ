# V2.3.1 Remaining Replication Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use $superpower-executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking via update_plan.

**Goal:** Finish the remaining V2.3.1 P1 replication hardening items in the order R3-P1-03, R3-P1-04, R3-P1-02, then R3-P1-08.

**Architecture:** Keep the existing segmented-log and broker replication design. Fix the storage and sendfile safety issues at their boundaries first, then add Controller-driven ISR lag lifecycle behavior using existing persisted replica LEO metadata.

**Tech Stack:** Java 17, Maven multi-module build, JUnit 5, Netty EmbeddedChannel, MiniMQ protocol/storage/broker modules.
